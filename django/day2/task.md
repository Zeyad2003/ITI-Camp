# Django Day2

You should have 3 pages.
- Home page contain the following: 
   - navbar (holds three links: Home, Students, Deleted)
   - Home contains a simple welcome message in the body.

- Students page contain the following:
    - A form that fetched the students from the backend and display them in a table.
    - The table shows the student name as a link, and delete button.
    - Clicking on the student name (link) shows another page with student details (name, age, email, address).
    - Clicking on the delete button removes the student from the students list and adds it to the deleted students list.

- Deleted page contains the deleted students.

The navbar and footer should remain to all pages.
Create a dummy list within backend without relying on db.
